# Fast-Track: Module 03 - Database Fundamentals
**Core Concept:** ACID vs BASE. B-Tree (reads) vs LSM-Tree (writes). SQL vs NoSQL. Relational Normalization.
**Case Study:** Airbnb
- **Key Insight:** Relational databases (PostgreSQL) are required for transactional correctness like booking a room (prevent double-booking).
- **Takeaway:** Use SQL when strict ACID guarantees are needed. Scale reads via Read Replicas.
