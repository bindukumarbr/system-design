# Fast-Track: Module 09 - API Architectures
**Core Concept:** REST vs GraphQL vs gRPC.
**Case Study:** WhatsApp API
- **Key Insight:** Use REST externally for clients, gRPC internally for low-latency microservice-to-microservice communication, and WebSockets for real-time delivery.
- **Takeaway:** Choose API protocol based on consumer needs. GraphQL prevents over-fetching; gRPC is best for internal speed/streaming.
