# Fast-Track: Module 20 - Serverless, Edge & AI
**Core Concept:** Lambda Cold Starts (Provisioned Concurrency), Edge Computing, RAG (Retrieval-Augmented Generation), Vector DBs.
**Case Study:** Robinhood
- **Key Insight:** Use Provisioned Concurrency for latency-sensitive market open order intakes. RAG pipelines must apply row-level ACL filtering in the vector DB to prevent data leaks.
- **Takeaway:** Edge computing is great for routing/auth, but stateful execution belongs at the origin.
